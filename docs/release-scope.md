# 本次开源范围

本次发布完整的现有桌面功能源码，包括标注、工程/样本管理、数据导入导出、检测增强、本地训练推理、训练分析、AI助手、项目上下文和选中照片操作。

## 包含

- `main.py`、`UI/`、`LabelItem/` 和当前运行所需的 `Utils/` 模块。
- 现有功能的合成数据/模拟接口测试。
- 软件现用样式与小图标。
- 合成示例生成器和对应界面截图。
- 安装依赖说明、用户文档、贡献指南、许可证、问题模板和测试工作流。

## 排除

- 用户工程、真实样本、正式标注、客户数据和数据划分文件。
- 私有/预训练模型、训练产物、模型推理结果。
- SQLite数据库、最近打开记录、API配置、聊天历史和人工问题记录。
- 内部开发接续文档、备份、分析日志与撤回版本。
- 与具体业务数据绑定的整理脚本、商用软件手册和旧交接压缩包。
- 旧构建产物，以及未被当前应用引用的历史 `Utils/yoloTool.py`。

以上排除项不影响现有桌面功能源码的完整性。首次运行自动建立本地运行数据；训练、推理及AI调用由使用者自行准备模型与接口。

基础实现维持原版；本次只在开源副本更新一项测试的旧错误提示断言，使其与当前候选采用保护行为一致。原工作目录中的应用源码与真实工程未因此变更。
