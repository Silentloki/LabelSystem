# 使用指南

## 打开第一个工程

完成 [README](../README.md) 的安装步骤，运行 `python examples/create_demo_project.py`，再运行 `python main.py`。在项目窗口选择 `examples/demo_project`。

示例图由程序绘制，包含两个缺陷样本、一个完全良品和一个未标注样本。它们用于体验操作，不是训练效果样本。

## 建工程与导入

1. 点击“新建工程”，填写工程名称、说明和任务类型。初版主要支持检测/矩形与分割/多边形工作流。
2. 导入待标注图片。工程会维护原图、标注和样本状态。
3. 有已有标注时，从文件菜单使用“导入标注”，按图片主名匹配 JSON。覆盖已有标注前会生成备份。
4. 导入 YOLO 时使用“导入数据集”，选包含 `images/`、`labels/` 与 `data.yaml` 的目录。同主名冲突会跳过；第一版不从外部导入子样本分类。

## 标注与样本管理

顶部第一行切换“标注 / 训练 / 推理”，右侧打开“AI 助手”；标注页第二行选择“阅读 / 矩形 / 多边形”等工具。

- 矩形用于目标框；多边形用于分割轮廓。
- 缺陷类别属于训练标签；子样本分类用于管理、复查和交付。
- 左侧树支持全部样本、状态、缺陷和子样本分类。
- 完全良品和过杀品是负样本。设为这两类状态会清除该图片的缺陷标注及子样本归类。
- 切换或结束编辑前核对保存状态；处理正式数据前建议复制工程备份。

多边形的详细交互以画布工具提示和当前程序行为为准；精确几何编辑由人工完成。

## 生成数据集

在生成数据集界面选择需要的正式缺陷类别，并按需加入完全良品与过杀品。

- 矩形导出为 YOLO 检测标签，多边形导出为 YOLO 分割标签。
- 良品和过杀品的 TXT 为空文件。
- 同源切图在 AI 数据集导出中保持同源分组，减少原图切片跨训练/验证划分的问题。
- 默认数据集导出复用软件划分规则；AI 助手的显式检测/分割格式可接受对应划分参数。
- 检测增强目前仅支持矩形标签的旋转/平移，增强训练集，验证集保持原样。

## 模型与结果

训练页选择数据配置和本地 `.pt` 权重；训练完成后可打开训练结果分析。推理页可加载模型、处理图片/目录/视频。

通过 AI 助手生成的候选预测单独保存，可与已有标注对照，核对后采用符合条件的候选。旧“自动标注”入口有直接写正式 JSON 的行为，使用时要明确其影响。

模型同名时，候选结果会展示模型指纹和来源，帮助区分不同 `best.pt`。它们不能替代模型适用性判断。

## 处理结果与导出

AI 筛选、切图、格式整理、预测等产物出现在临时结果或聊天卡片中。可以重开、筛选、多选、隐藏/恢复、查看删除清单。

导出时说明范围与内容，例如“导出这组图片和 JSON”“只导出选中的图片”“导出带预测框的预览”。预测记录与正式训练标签保持区别。

结果预览支持滚轮缩放；右键“适应窗口”可恢复整体显示。移动项目请复制完整工程，保留 `ai_workbench/` 以继续使用资源和历史。
